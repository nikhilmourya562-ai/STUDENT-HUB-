# StudentHub — PPT, Posters & Study Services

This package is prepared for uploading to a GitHub repository and publishing with GitHub Pages.

## Files
- `index.html` — the website homepage (renamed from the supplied HTML file).

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish; the public URL will appear in the Pages section.

Note: This ZIP contains the supplied HTML page only. If the page depends on external services or files not embedded in the HTML, those dependencies must also be configured or uploaded.
